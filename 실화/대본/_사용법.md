# 실화 대본 → PC에서 MP4 만들기

이 폴더의 `*.json`은 **나레이션 대본이 이미 완성된** 프로젝트 파일입니다.
클라우드(여기)에서는 음성·영상을 못 만들므로, **PC에서 아래 한 줄**로 사진·나레이션·MP4까지 만듭니다.

## 준비
1. `깃허브_최신받기.bat`으로 최신 내용 받기
2. 음성 엔진(supertonic)과 Claude Code가 평소처럼 동작하는 상태인지 확인

## 영상 만들기 (한 편)
명령 프롬프트(또는 PowerShell)에서 프로그램 폴더로 간 뒤:

```
py -3.11 -X utf8 render_project.py "실화\대본\1_별불가사리.json" --소재프로필 --사진 --kit
```

- `--소재프로필` : 이 소재의 기본 다큐 스타일(자막·제목 위치·근거 사진·웹 조사)을 자동 적용
- `--사진` : 대본에 맞는 **근거 사진을 웹에서 자동으로 찾아 넣음**(나레이션 15초에 한 장 목표). 뒤에 숫자를 붙이면 간격 조절 → `--사진 12`
- `--kit` : 업로드 제목·설명란·유튜브 썸네일까지 생성

결과: `output\장문\<제목>.mp4` (+ 썸네일, 타임스탬프, 업로드 문구)
중간에 꺼져도 다시 같은 명령을 실행하면 사진·나레이션·영상 구간을 **이어서** 만듭니다.

## 네 편 전부 만들기 (PowerShell)
```
Get-ChildItem "실화\대본\*.json" | ForEach-Object { py -3.11 -X utf8 render_project.py $_.FullName --소재프로필 --사진 --kit }
```

## 대본을 고치고 싶으면
각 `.json`의 `story` 안을 고치면 됩니다.
- 빈 줄로 문단 구분, `## 1. 제목` 처럼 쓰면 챕터 제목
- `sources`(출처)·`notes`(확인 주의)도 그대로 두면 설명란·검증에 쓰입니다
