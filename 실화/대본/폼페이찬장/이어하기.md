## 되살리는 법 (새 서버)
```
W="output/장문/_작업_1,947년 동안 화산재에 갇혀 있던 찬장, 폼페이 집에서 나온 아이 부"
mkdir -p "$W" output/장문/media
cp 실화/대본/폼페이찬장/대본.json "$W/대본.json"
cp 실화/대본/폼페이찬장/media/* output/장문/media/
echo done > "$W/사진보강_완료.txt"
xvfb-run -a .supertonic_venv/bin/python -X utf8 make_longdoc.py --실화 --한편      # 나레이션 다시 녹음(약 5분) → 사진 점검에서 멈춤
```
- 대본.json 의 사진 줄은 `output/장문/media/<파일>` 경로라 위처럼 복사하면 그대로 맞음
- 사진을 더 넣을 땐 `대본.json` 과 `output/장문/<제목>_프로젝트.json` 의 story 둘 다에 넣음(다시 실행하면 대본.json 에서 프로젝트를 새로 씀)
- 다시 실행하면 30초 후크·존댓말 검사(AI)가 한 번 더 돌 수 있음 → 문장이 바뀌었으면 받아쓰기 검사를 다시
