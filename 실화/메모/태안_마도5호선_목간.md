# 기획메모: 태안 마도 5·6호선 — 고려 난파선 목간 30점 (2026-11-04 발표)

## 왜 이 주제 (사용자 선택 2026-11-04)
- 채널 인기 줄기 = 문자·기록 + 한국 (쿠샨 17만·선형 엘람 1만·한국인 DNA 1.6만)
- 발표 당일. 한국어 영상은 방송 뉴스 2~3분 클립뿐(JTBC 9.5만·연합뉴스TV 2.7만·MBC 1.6만, 10시간 안) → 긴 영상 빈자리, 수요 확인됨

## 확인된 사실 (출처 그대로)
- 발표: 국가유산청 국립해양유산연구소, 2026년 11월 4일 충남 태안 수중발굴조사 성과 언론공개회. 올해 조사는 11월 7일까지
- 목간 30점: 마도 5호선 26점, 마도 6호선 4점
- 마도 5호선: 지난해(2025) 음파탐사에서 청자 다발·선체 조각 → 올해 정밀 발굴, 유물 54점(목간 26점, 닻돌·밧줄·화물 받침목·볏섬·청동호)
  · 목간 글: '정묘년(丁卯年)'·'정묘 12월(丁卯十二月)', 발송지 영암군·안로현(현 전남 영암 금정면 일대), 목적지 '경(京)' = 개경
  · 품목: 벼·쌀(현미)·백미·콩·흰콩, 수량, 받는 사람 관직·성씨, 한 석에 담은 양
  · '별장 장씨 집에 쌀 12석'(보낸 사람 영암군 전 부호장), '고위 관료 곽씨의 부인 집에 콩 10석'(여성이 받는 사람)
  · '전주(田主)' 처음 나옴(태안선~마도 4호선 목간에 없던 글자, 수조권과 연결 — 문경호 공주대 교수), '재경(在京)'(개경에 사는 지방 출신)
  · 5호선 20번 목간 = 안로현 → 개경 송득덕. 2009년 마도 1호선 34번 목간과 받는 사람·글씨 모양이 거의 같음 → 같은 사람이 썼을 것으로 추정
  · 두 배는 약 250m 떨어짐. 외판재가 다름(1호선 두꺼운 통나무 덜 다듬음, 5호선 판재로 다듬음) → 다른 배, 같은 선단 가능성에 무게
- 연대: 유기물 5점 방사성탄소 + 청자 제작 시기 → 정묘년 = 1207년. 가을 곡물을 겨울까지 조창에 모아 이듬해 봄 개경으로 → 1208년 봄 항해 추정(1호선과 같은 시기)
- 마도 6호선: 2호선에서 동쪽 약 110m, 목간 4점·볏섬·화물 받침목·청자유병·도기정병 등 20여 점. 선체는 아직 확인 못 함(흔적만)
  · 목간: 사주(泗州, 현 경남 사천)의 향리 우두머리, 반성(班城, 현 진주 반성면) 인물이 화물을 보냄 → 경상도에서 출발한 조운선 흔적 처음(그동안 태안 해역 고려 화물선 목간 발송지는 모두 전라도). 사천 조창 통양창 경유 추정
- 같은 날 인양 도자기는 5·6호선과 별개 — 조선 내섬시 '내섬(內贍)' 명문 분청사기 등
- 현장: 수심 약 13m, 잠수사 50kg 장비, 바다 위 승강기
- 배경: 안흥량 = 조류 거세고 암초 많아 '난행량(難行梁)'. 2007년 주꾸미잡이 중 청자 발견 → 태안선(청자 약 2만3천 점) → 2009년부터 마도 1~4호선('바다의 경주').
  마도 1호선 = 1208년 침몰(목간·죽찰). 마도 4호선 = 조선 조운선(2025년 인양, 현존 유일 조선 선박). 고려 선박 상당수가 무신정권기(1170~1270)에 침몰 → 왜 그 시기에 많이 다니고 가라앉았는지는 과제
- 앞으로: 내년 5호선 남은 구역 발굴, 6호선 선체 확인 정밀 조사, 무인수상정 + 여러 탐사 장비

## 주의 (사실 규칙)
- 1207년·1208년 봄·같은 선단·같은 사람이 썼다 = 연구진 추정 → '추정', '가능성'
- 6호선은 선체 확인 전 → '6호선으로 보는 흔적'
- 목간 수량 예전 숫자(1~4호선 몇 점)는 보도마다 달라 쓰지 않음
- 발음: '유적' 쓰지 않음. '마도 5호선' 읽기 확인(오 호선), '정묘년', '안로현', '사주' 같은 낱말 받아쓰기로 확인
- 사진: 국가유산청·korea.kr 보도자료 사진(공공누리 유형 확인), 위키미디어 태안·청자, 국립중앙박물관 등 공공누리 1유형. 뉴스 통신사 사진은 쓰지 않음
- 배경음: 한국 악기 선율(가야금·해금) — 가락 있는 것 (CLAUDE.md 4장)
