# 기획메모: 폼페이 비아 델라본단차 집의 나무 찬장 — 아이 부적 목걸이(크레푼디아)
## 확인된 사실 (2026-10-29~30 보도, 로이터·Archaeology Magazine·GreekReporter)
- 폼페이 중심가 '비아 델라본단차(풍요의 거리)'의 한 집에서 나무 찬장(옷장)을 찾음.
- 나무는 남지 않았고, 화산재·흙에 찍힌 자국으로 찬장 모양을 되살림.
- 안에서 나온 것: 작은 물건 24개 이상을 꿴 부적 목걸이(크레푼디아) — 뼈·유리 반죽·도기·수정, 이집트 신 베스와 로마 신 메르쿠리우스 모양 포함.
  화장품, 유리 향수병, 족집게, 향로, 요리 그릇, 나무 상자 속 납 저울추(장사용 추정), 작은 바구니 속 청동 동전 38닢.
- 크레푼디아 = 로마 아이에게 주던 부적 겸 딸랑이. 어른이 되어서도 어린 시절 기념으로 간직하기도 함.
- 베수비오 화산 폭발: 서기 79년 → 2026년까지 약 1,947년.
## 주의 (사실 규칙)
- 집 주인 '코르넬리우스 막시무스'는 지금은 읽을 수 없는 옛 글씨에 기댄 추정 — 연구진도 의심. 유적 소장 가브리엘 추흐트리겔: "누가 살았는지 확실히 되살릴 수 없다" → '추정'으로만.
- 주인이 피했는지 숨졌는지 아직 모름 → 열린 질문으로 마무리.
- 재료 목록은 매체마다 조금 다름(파이앙스 포함 여부) → '뼈·유리·수정 같은 재료' 정도로.
- '찬장/옷장' 표현도 매체마다 다름 → '나무 수납장(찬장)'.
- 이 집이 '정숙한 연인들의 집(Insula dei Casti Amanti)' 구역이라는 말은 한 곳 보도뿐 → 확인 전엔 쓰지 않음.
