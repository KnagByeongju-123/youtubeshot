# 기획메모: 샤니다르 A — 7만 5천 년 전 나무 창 상처
## 확인된 사실 (출처에 있는 것만)
- 논문: Pomeroy 외, Scientific Reports, 2026년 10월 15일 발표. 이라크 쿠르디스탄 샤니다르 동굴.
- 새로 확인된 네안데르탈인 '샤니다르 A', 약 7만 5천 년 전.
- 어깨뼈(견갑골)에 동그란 구멍 — 가슴 앞쪽으로 들어간 창이 뒤로 빠져나간 '출구 상처'로 해석. 모양이 돌촉 창보다 나무 창 실험 상처와 더 잘 맞음.
- 죽을 무렵 생긴 상처. 사냥 사고인지 폭력인지는 알 수 없음. 현장에서 창 자체는 나오지 않음.
- 그보다 몇 년 전 얼굴에 큰 부상을 입고도 살아남은 흔적(부러진 이) → 누군가 돌봐 줬을 가능성(연구진 제안).
- 연구진: 나무 창으로 죽은 인류 친척의 가장 이른 증거일 수 있음. 외부 학자 브뤼노 모레유: 나무 창이 '의심할 여지 없이' 맞다. Live Science: 이 동굴에서 가장 많이 사냥한 야생 염소 뿔도 비교 대상.
- 샤니다르 동굴: 1950~60년대 랠프 솔레키 발굴, '꽃 무덤'(샤니다르 4)으로 유명, 샤니다르 1은 팔이 불편한데도 오래 산 사람. 2018년부터 새 발굴(샤니다르 Z, 2024년 넷플릭스 다큐로 얼굴 복원).
## 구성 제안
훅(7만 5천 년 전 동그란 구멍 하나) → 샤니다르 동굴과 꽃 무덤 → 새 발굴과 샤니다르 A → 구멍이 말해 주는 것(출구 상처·나무 창 실험) → 사냥 사고일까 다툼일까(양쪽 근거, 염소 뿔 가설) → 얼굴 부상과 돌봄 → 폭력과 돌봄을 함께 가진 친척 → 아직 풀리지 않은 것
## 주의
- 살인이라고 단정하지 말 것 ('누가 던졌을까?', '사고였을까'). 창은 발견되지 않았음.
