# 기획메모: 217년 된 나폴레옹 시대 암호 편지, AI 가 몇 시간 만에 풀다 (2026년 9~10월)

## 왜 이 주제 (사용자 선택 2026-11-05: 잉카 편 다음)
- 채널 최고 인기 줄기 = 못 읽던 문자·암호 해독(쿠샨 17만). 한국어로 이 소식을 다룬 영상 없음(2026-11-05 검사)

## 확인된 사실 (보도마다 조금 다름 → 원 기록 확인 필요)
- 해독한 사람: 카터 처치(Carter Church), 보안 회사 센티넬원(SentinelOne) 엔지니어, 27세(일부 보도). 암호 해독 경험 없었다고 본인이 말함
- 도구: 오픈AI 의 GPT-6 Astra 모델(보도). 스캔한 편지 그림을 옮겨 적고 암호를 풀었음
- 편지: 1809년 3월 말로 다시 연대를 매김(예전엔 1807년으로 알려짐). 외젠 드 보아르네(나폴레옹의 의붓아들) 사령부에서 나폴레옹 명령으로 오귀스트 드 마르몽 장군에게 보낸 군대 배치 지시 — 나폴레옹이 직접 쓴 편지는 아님
  · 내용 한 대목: 몇몇 분견대에 겁먹지 말라는 뜻
- 암호: 동음이의 치환 암호(같은 글자를 여러 기호로 바꿈). 암호 단위 약 1,300개, 서로 다른 기호 155개. 역사가 다니엘 탕(Daniel Tant)의 부분 표가 약 435단위를 풀었었음
- 시간: 모델 실행 약 6시간(대부분 보도), 10시간이라는 보도도
- 검증: 암호 연구 사이트 Cryptiana 운영자 도모키요 사토시(Satoshi Tomokiyo)가 검토하고 '풀림'으로 표시. 처치는 9월 18일 옮겨 적은 글·스크립트까지 전체 연구 기록을 공개
- 본인 말: 전문가가 시간을 들이면 AI 없이도 풀 수 있었을 것

## 주의
- 학술 논문이 아님 → '엔지니어가 공개한 연구 기록', '전문가 검토'
- 6시간/10시간, 9월 18일/30일, 27세 등 보도 차이 → 원 기록(처치의 글·Cryptiana)으로 확인한 것만
- '나폴레옹의 편지'라고 하지 않음 → '나폴레옹 시대·나폴레옹 명령으로 보낸'
- 배경음: 19세기 초 유럽 → 새 가락 필요(예: 하프시코드·현악 느낌)
