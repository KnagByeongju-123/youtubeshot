# 기획메모: 홀리 — 인도 사람들은 왜 서로에게 물감을 던질까 (사용자 요청 2026-11-08)
## 확인된 사실 (출처에 있는 것만)
- 홀리: 힌두 달력 팔구나 달 보름(양력 보통 3월, 가끔 2월 말). 하룻밤 + 하루. 봄이 온 것과 봄 수확을 비는 축제. 2026년은 3월 3일 밤 홀리카 다한, 3월 4일 물감 놀이.
- 오래된 기록: 굽타 시대보다 앞섬. 자이미니의 『푸르바 미맘사 수트라』·『카타카 그리햐 수트라』에 나옴, 『나라다 푸라나』·『바비샤 푸라나』에 더 자세히.
  7세기 하르샤 왕의 희곡 『라트나발리』에 '홀리코차브(holikotsav)'. 4세기 찬드라굽타 2세 때 칼리다사 작품, 단딘의 『다샤쿠마라 차리타』에도.
  12세기 벨루르 첸나케샤바 사원 부조, 15세기 함피 부조에 홀리 장면.
- 이름: 영어 사전(OED)에 1687년 'Houly', 1698년 'Hooly', 1789년 'Huli', 1809년 'Hohlee', 1825년 'Hoolee' → 1910년 뒤 'Holi'.
- 전설 1 (『바가바타 푸라나』 7장): 악한 왕 히란야카시푸, 비슈누를 믿는 아들 프라흘라다. 불에 타지 않는 고모 홀리카가 아이를 안고 불 속에 앉았지만 홀리카만 탐 → 홀리 전날 밤 모닥불 '홀리카 다한'(작은 홀리), 선이 악을 이긴 것.
- 전설 2: 피부가 검은 크리슈나가 라다가 싫어할까 걱정 → 어머니 야쇼다가 라다 얼굴에 색을 칠해 보라고 함 → 둘의 색칠 장난을 기념. 브라지(마투라·브린다반) 지역, 브린다반은 16일 동안.
  바르사나 라다 라니 사원의 '라트마르 홀리'(여자들이 막대로 남자를 때리는 놀이, 2026년 2월 말).
- 전설 3: 시바가 사랑의 신 카마를 태움 → 아내 라티가 40일 고행 → 되살아남.
- 역사 기록: 무굴 황제 아우랑제브가 1665년 11월 칙령으로 공공 홀리를 금지. 시크 왕국 란지트 싱의 라호르 궁정은 1837년 홀리에 물감 300몬드(마운드)를 씀, 영국 장군 헨리 페인도 참가.
  벵골은 약 500년 전 차이타냐가 브린다반에 다녀온 뒤 시작했다고 전함. 파키스탄은 1947~2016년 공휴일 아님, 2016년 의회 결의로 공휴일.
- 원래 물감 재료(자연): 팔라시(숲의 불꽃, 테수) 꽃 = 빨강·주황, 강황 = 노랑, 헤나·굴모후르 잎 = 초록, 비트 = 자홍, 인디고·자카란다 = 파랑, 숯 = 회색·검정. 님·빌바·쿰쿰은 약초 재료.
  봄철 감기·피부병을 막는 약초였다는 설명은 전해지는 말(과학 증명 아님 → '그렇게 전해진다').
- 요즘 문제: 2007년 연구 — 합성 염료 말라카이트 그린이 델리에서 심한 눈 자극과 관련. 2009년 연구 — 금속 성분 공업 염료가 홀리 뒤 며칠 피부 문제, 표시 없이 팔리는 경우가 많음.
  인도 전문가들이 2026년에도 합성 가루의 눈 긁힘·감염을 경고. 중금속 색소가 하수를 잠시 오염(약 5일 안에 회복).
- 세계로: 네팔·방글라데시·파키스탄, 카리브해(트리니다드토바고·가이아나·수리남 '파그와'), 피지·모리셔스·남아공.
  미국 유타 스패니시포크 라다 크리슈나 사원 행사, 뉴욕 2014년 5월 브루클린 수천 명, 영국 버밍엄에서 시작한 음악 행사 '홀리 원', 컬러런 같은 달리기.
- 배경음: 인도 전통(시타르·반수리) · 카피
## 구성 제안
훅(하늘을 덮는 색 구름, 모르는 사람 얼굴에 물감) → 왜 하필 봄 보름날인가 → 전날 밤 모닥불(홀리카와 프라흘라다) → 크리슈나와 라다의 색 장난, 브라지의 16일 → 막대로 때리는 라트마르 홀리 →
1,500년 넘는 기록(경전·라트나발리·사원 부조·영어 이름 변천) → 황제의 금지와 왕의 300몬드 → 꽃으로 만든 색 vs 공장 염료 → 세계로 퍼진 홀리(컬러런) → 색이 지우는 것(신분·나이 경계)
## 주의
- 연도가 불확실한 '기원전 300년 람가르 비문' 같은 말은 쓰지 않음. 경전 연대는 '아주 오래된'·'굽타 시대보다 앞선'으로.
- 성희롱·사고 같은 부정적 장면을 자극적으로 다루지 않음(안전 수칙 정도로만).
- 사진은 위키미디어 공용(CC)에서, 사람 얼굴 사진은 3D 변환 안 함(사용자 결정 2026-11-08).
