# AI 공유 쪽지함 사용법

Claude(이 폴더의 Claude Code)와 Codex(ChatGPT)가 같은 short_ 폴더를 통해 파일로 협업합니다.
둘은 직접 대화하지 못하므로, 사용자가 한 번씩 "이 파일 읽어줘"라고 연결해 줍니다.

## 폴더
- claude가codex에게.md : Claude가 그림 프롬프트·요청을 적어 둠
- codex가claude에게.md : Codex/사용자가 완료·변경을 알림
- 받은그림\ : Codex가 그린 그림을 번호_이름.png 로 저장

## 흐름 (영상 그림 예)
1. Claude가 대본을 보고 claude가codex에게.md 에 그림 프롬프트를 적는다.
2. 사용자가 Codex에게 "claude가codex에게.md 읽고 받은그림 폴더에 그려줘"라고 한다.
3. Codex가 받은그림\ 에 번호 순서대로 저장한다.
4. 사용자가 Claude에게 "받은그림 확인하고 영상 만들어줘"라고 한다.
5. Claude가 그림을 대본에 넣고 영상을 만든다.

## 역할 분담 (각자의 장점대로)

| 단계 | 맡는 쪽 | 이유 |
|---|---|---|
| 주제·제목 아이디어, 썸네일 문구 | ChatGPT(Codex) 또는 함께 | 빠른 발상·창작 |
| 대본 집필, 사실 확인(웹 조사) | Claude | 긴 글·최신 연구 검증 |
| 그림 프롬프트 작성 | Claude | 대본 내용·인물 외모에 맞춰 |
| 이미지 생성 | ChatGPT(Codex) | 화사한 유화·인물 그림 품질이 좋고 빠름 |
| 그림 배치·영상 제작·업로드 문구·썸네일 | Claude | 파일을 직접 다루는 긴 자동 작업 |
| 프로그램 수정·새 기능·깃허브 | Claude | 파이썬 코드·자동화 |

### Codex가 잘하는 것
- ChatGPT 이미지 생성 (로컬 그림보다 빠르고 예쁨)
- 짧은 창작: 제목 후보, 썸네일 문구, 아이디어 브레인스토밍

### Claude가 잘하는 것
- 파이썬 프로그램 수정·새 기능·깃허브 관리
- 파일을 직접 다루는 긴 작업: 대본 집필, 그림 배치, 영상 제작, 나레이션 발음 교정, 파일 정리
- 웹 조사로 최신 사실 확인

## 기본 협업 흐름 (영상 한 편)
1. (함께 또는 Codex) 주제·제목을 정한다.
2. Claude가 대본을 쓰고(사실 확인 포함) 그림 프롬프트를 claude가codex에게.md 에 적는다.
3. 사용자가 Codex에게 "claude가codex에게.md 읽고 받은그림 폴더에 그려줘"라고 한다.
4. Codex가 받은그림\ 에 번호_이름.png 로 저장하고, codex가claude에게.md 에 "다 넣었어"라고 적는다.
5. 사용자가 Claude에게 "받은그림 확인하고 영상 만들어줘"라고 한다.
6. Claude가 그림을 대본에 넣고 영상·썸네일·업로드 문구를 만든다.
