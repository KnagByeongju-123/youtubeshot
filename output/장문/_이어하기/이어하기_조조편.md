# 이어하기 — 정사 삼국지 인물 열전 1편 (조조 「무제기」)

이전 세션 서버가 바뀌어 AI 계산 기능(AMX)이 없어져(그림 한 장 25분) 새 세션에서 이어서 함.
이 가지(`transfer/jojo-ep1`)에 작업물이 들어 있음. 녹음 캐시(tts_cache)·영상 조각은 무거워서 빼 두었음 → 렌더 때 다시 만들어짐.

## 받는 법 (새 세션 처음에)
```
git fetch origin transfer/jojo-ep1
git checkout origin/transfer/jojo-ep1 -- output/장문
grep -c amx_bf16 /proc/cpuinfo     # 0 이 아니어야 함 (0 이면 또 새 세션)
```
작업 가지는 main 에서 새로 (transfer 가지에는 커밋하지 않음, 다 끝나면 transfer 가지는 지워도 됨).

## 이미 끝난 것
- 대본(3장, 약 11분)·사실 확인 완료. 첫머리 두통약 문장 복원, 1장 첫 문장 중복 정리, 끝 예고 중복 삭제
- 프로젝트 settings: 롱폼 가로(1920×1080), head_show 안 보임, img_label off, img_depth off, 배경음 중국 현악(고쟁·얼후)=궁조, 타악 기본 끔
- 그림 71장 검수·다시 그리기 완료 (유리 등잔·양장본·유럽 범선·형광등·서명/도장·가짜 글자 등 고침)
- 캐릭터 시트: 조조·진수·배송지·관우·서영·유비 = 사용자 확정 시트(`등장인물/삼국지/`), 나머지 `output/장문/media/_cast/`
- 썸네일 후보 22장·설명란·업로드 문구·재생목록/고정댓글 (0001_… 폴더)

## 남은 순서
1. **시트 바로잡기** (사용자 지적): 조등 = 환관이라 수염 없음, 하작 = 안경 없음 (청나라엔 안경이 있었지만 시청자가 어색해함)
   ```
   .sd_venv/bin/python -X utf8 -u klein_worker.py models/FLUX2_klein_4B output/장문/_이어하기/시트_조등_하작.json output/장문/_이어하기/시트
   ```
   → 결과를 `output/장문/media/_cast/조등.png`, `하작.png` 에 덮어씀 (크게 열어 수염·안경 없는지 확인). 프로젝트 cast 의 look 은 이미 고쳐 둠
2. **안경 없는 하작 장면**: `output/장문/_이어하기/하작_안경없이.json` 을 klein 으로 → 1600×900 JPG 로 `output/장문/media/aiimg_20261030_222233_11.jpg` 에 덮어씀
3. **그림 간격 (5~15초, 사용자 결정)**:
   `xvfb-run -a .supertonic_venv/bin/python -X utf8 그림_간격_보강.py "<프로젝트.json>"` (새 그림 약 8장, 조등·하작 나오면 새 시트로)
   → 새 그림 크게 열어 검수 (팔·다리·손 수, 글자·도장, 테두리, 시대에 안 맞는 소품: 유리 등잔·양장본·유럽식 배·전등 자주 나옴)
4. `xvfb-run -a .supertonic_venv/bin/python -X utf8 인물영역_만들기.py "<프로젝트.json>"` → `_인물영역_확인_N.png` 크게 열어 검수
5. 프로젝트 settings 의 format 이 `롱폼 가로(1920×1080)` 인지 확인
6. `xvfb-run -a .supertonic_venv/bin/python -X utf8 render_project.py "<프로젝트.json>" --대본그대로 --길이고정 --형식고정`
   (새 그리는 효과: 먹선 스케치 → 배경 색 → 인물 색(붓 획), 인물 자리 흐림 없음)
7. `.sd_venv/bin/python 나레이션_겹침검사.py <영상.mp4> <회차.py> --고치기 <프로젝트.json>` → '겹침·빨라진 곳 없음'까지 (최대 3번)
8. 완성 영상·썸네일·설명란 파일을 사용자에게 보냄
9. `역사/주제목록.txt` 의 1편(조조) 줄 앞에 `#` → 커밋·푸시, main 에 합침
10. 썸네일 문구: 프로그램이 고른 '아무도 몰랐던 1800년 간웅' 은 과장 → '본문엔 없던 1800년 간웅' 같은 대안도 함께 제안

`<프로젝트.json>` = `output/장문/0001_1,800년 '간웅'으로 불린 조조, 정사 「무제기」를 펴자 드러난 반전/1,800년 '간웅'으로 불린 조조, 정사 「무제기」를 펴자 드러난 반전_프로젝트.json`
