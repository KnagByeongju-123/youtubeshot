# 역사 채널 기획 — 기록으로 보는 진짜 역사

> 기존 계정(@sailormoon2756)을 바꿔서 쓰는 계획. 조선왕조실록 + 정사 『삼국지』를 한 채널로 묶음.

## 한 줄 정체성
**"사극과 소설이 바꿔 놓은 장면, 실제 기록에는 이렇게 적혀 있다."**

실록과 정사는 다른 나라·시대지만 둘 다 **"알려진 이야기 vs 실제 기록"**이라는 같은 반전을 가진다.
그래서 한 채널에 섞어도 시청자와 유튜브가 헷갈리지 않는다.

## 채널 이름 후보
| 이름 | 느낌 |
|---|---|
| **기록의 반전** | 공식(반전)이 이름에 들어감. 가장 추천 |
| 사관의 붓 | 실록 느낌이 강함. 삼국지(진수도 사관)와도 통함 |
| 진짜 역사 기록관 | 쉽고 검색이 잘 됨 |
| 실록과 정사 | 정직하지만 딱딱함 |

- "sailor moon"은 유명 만화의 상표라 꼭 바꿈 (검색에서도 원작에 묻힘)
- 핸들(@주소)도 이름에 맞게 바꿈. 바꾸면 예전 주소는 나중에 다른 사람이 가져갈 수 있음

## 채널 소개 (복사해서 쓰기)
```
드라마와 소설이 바꿔 놓은 역사, 실제 기록은 무엇이라고 말할까요?
조선왕조실록과 정사 『삼국지』를 펼쳐, 우리가 알던 장면과 진짜 기록을 나란히 놓고 봅니다.
기록에 있는 것은 기록대로, 소설·야사·해석은 분명히 구분해서 전합니다.
```

## 프로필·배너
- 프로필: 붓과 오래된 책(실록 표지 느낌)을 klein 으로 그림. 실제 인물 얼굴은 쓰지 않음
- 배너 문구: "알던 역사 vs 기록된 역사"

## 올리는 규칙 (지난 실패에서 배운 것)
1. **하루 1편 이하.** 같은 날 같은 틀로 여러 편 올리면 '찍어 낸 영상'으로 보이기 쉬움
2. **처음 10편은 10~15분.** 구독자가 적을 때 30분은 끝까지 보는 비율이 낮게 찍힘
3. **제목 틀을 돌려 씀.** "~는 없었다" / "~는 진짜였다" / "기록 한 줄이 밝힌" / 숫자형을 번갈아 (주제목록.txt 가 이미 섞여 있음)
4. **판단은 올린 지 7일 뒤에.** 그 전 조회수로 실패라고 보지 않음
5. **실록과 삼국지를 번갈아.** 어느 쪽 시청자가 더 반응하는지 10편 뒤 비교
6. 기존 사이다 영상 3편과 「두 번째 새벽」은 비공개로 돌리는 것을 검토 (채널 주제가 섞여 보이지 않게)

## 사실·저작권 규칙
- 실록·정사 **원문**(한문)은 옛 기록이라 누구나 쓸 수 있음
- **한국어 번역문**은 번역한 기관·사람의 저작물일 수 있음 → 길게 그대로 옮기지 않고 자기 말로 풀어 씀, 직접 인용은 한두 문장 + 출처
  (국사편찬위원회 조선왕조실록 사이트의 정확한 이용 조건은 아직 확인 못 함 — 사이트의 이용안내를 확인할 것)
- 출처 표시: 실록은 "○○실록 ○○ ○년 ○월 ○일", 정사는 "『삼국지』 ○서 「○○전」", 배송지 주는 "배송지 주에 인용된 『○○』"
- 설명란에 출처 목록을 꼭 넣음

## 만드는 법
1. `역사\주제목록.txt` 에 주제가 20편 들어 있음 (실록·삼국지 번갈아, ⚠는 대본 단계에서 다시 확인)
2. `역사_연속제작.bat` 실행 → 순서대로 다큐 제작 (진행 기록은 실화 채널과 따로 저장)
3. 다 만든 줄은 앞에 `#` 를 붙임
