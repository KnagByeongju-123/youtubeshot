# 쇼츠 스크롤 영상 메이커 PRO

유튜브 쇼츠용으로 글이 위로 천천히 스크롤되는 세로 영상(1080×1920 MP4)을 만드는 파이썬 프로그램입니다.
허구 단편소설 · 기이한 실화 · 과학 사실 · 자연현상 · 올드 팝송 이야기(가사 원문+해석, 가수 실화) · 명화 이야기(세계·한국 명화의 배경 이야기)를 다룹니다.

## 설치
```
pip install pillow numpy imageio-ffmpeg
python shorts_novel_maker.py
```
AI는 PC에 설치된 Claude Code(`claude -p`)를 Max 구독으로 사용합니다. API 키는 필요 없습니다.
터미널에서 `claude`를 한 번 실행해 로그인해 두세요.

## 주요 기능
- AI 대본: 3안 작성 후 편집장 심사, 웹 검색 조사, 대본 평가, 사실 검증, 업로드 문구(제목·설명·해시태그)
- 근거 사진: AI 검색(위키미디어 등 공개 사진), 복사→붙여넣기(Ctrl+V), 파일 첨부
- 배경음: 13가지 자체 합성(저작권 없음) + 올드 팝송 멜로디 오르골 연주 + 반전 효과음, 이름 지정 저장
- 나레이션: 성우 선택 창에서 엣지 음성(무료), ChatGPT 음성 11종, Gemini 음성 30종 중 선택·미리듣기. ChatGPT·Gemini 음성은 "차분한 다큐 내레이터처럼" 같은 연기 지시 가능(API 키 필요). 윈도우 내장 음성은 오프라인 대체. 켜면 스크롤이 읽는 속도에 맞춰 움직이고 말할 때 음악이 줄어듦
- 다른 언어 버전: 영어·일본어 대본 번역 → 언어별 프로젝트·MP4·업로드 문구 자동 생성 (번역 AI: ChatGPT/Gemini API 키가 있으면 사용, 없으면 Claude. API 방식이라 채팅 기록에 남지 않음)
- 롱폼: 가로 1920×1080, 챕터(`## 제목`) 묶음 자동 생성, 챕터 타임스탬프 txt 자동 저장(설명란용)
- 표현 방식 2가지: 스크롤형(글이 흐름) / 자막형(큰 제목 + 가운데 사진 천천히 확대 + 아래 자막, 나레이션에 맞춰 장면 전환)
- 대본 작성·번역 AI 선택: Claude(기본, 웹 검색 가능) / ChatGPT / Gemini (API 키, 채팅 기록에 안 남음)
- 영상: 60fps 부드러운 스크롤, 제목 카드, 읽는 줄 강조, 테마 6종, 쇼츠 안전영역 (1분 ≈ 8MB)
- MP4 만들 때 배경음을 직접 선택(현재 설정·음악 파일·없음)하고, MP3로 따로 저장 가능
- 연속 제작: 여러 편을 주제 선정→대본→검증→MP4→썸네일→업로드 문구까지 자동
- 하단 AI 명령어로 "글자 크게", "결말 더 소름돋게", "배경음 빗소리로" 같은 수정

## 올드 팝송 저작권 기준
- 가사·멜로디는 1929년 이전 발표곡만 사용 (미국 퍼블릭 도메인). 1930년 이후 곡은 이야기만.
- 원곡 음원은 쓰지 않고 프로그램이 멜로디를 직접 연주합니다.

## 명화 이미지 저작권 기준
- 화가가 1955년 이전에 사망한 작품만 그림 이미지를 넣습니다(사후 70년 경과, 위키미디어 공용 PD-Art).
- 그 이후 사망한 화가(피카소, 박수근, 이중섭 등)는 이야기만 쓰고 이미지는 자동으로 뺍니다.
