## 장면표

|---|---|---|
| 0–6 | 운동장 (아침, 연습) | 출발선에 다섯. 출발! 넷은 앞서 달려 나가고 하준은 보조기 다리로 천천히 → 트랙 위에 혼자 남아 멈춰 다리를 내려다봄 |
| 6–11 | 또 꼴찌 (흐린 오후) | 트랙 가에 하준이 혼자 앉아 고개를 숙임. 멀리 결승선 쪽에서 넷이 뛰어놂 |
| 11–17 | 손 내밈 (노을) | 서연이 돌아와 옆에 앉음 → 일어나 손을 내밀어 하준을 일으킴 → 둘이 나란히 천천히 걸음 |
| 17–23 | 날마다 | 하늘색이 아침·낮·저녁으로 바뀌며 둘이 트랙을 나란히 달림. 하준이 조금씩 빨라짐. 친구 셋이 트랙 가에서 바라보다 손을 흔듦 |
| 23–29 | 운동회 날 | 만국기·천막. 출발선에 다섯. 출발! 넷이 앞서 나가고 하준은 뒤처짐(처음 장면과 같은 구도) |
| 29–34 | 멈춤 | 결승 테이프 바로 앞에서 넷이 멈춰 뒤를 돌아봄. 서연이 먼저 되돌아 뛰고, 셋도 따라감 |
| 34–40 | 손잡기 | 넷이 하준 양옆에 서서 손을 잡음 → 다섯이 한 줄로 손잡고 걸어감 |
| 40–45 | 함께 | 다섯이 동시에 테이프를 끊음(테이프가 양쪽으로 떨어짐), 잡은 손을 하늘로 번쩍. 카메라가 천천히 멀어지며 끝 |
