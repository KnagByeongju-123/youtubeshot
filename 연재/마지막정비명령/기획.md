# 「마지막 정비 명령」 — 로봇과 인간 단편 (약 10분, 일본 애니풍)

> 사용자 결정 2026-10-31: 연재(N화) 대신 한 편으로 끝나는 단편. 《두 번째 새벽》 1화(로봇과 소녀)가 1천 회까지 추천받았던 공식을 이어 감.
> 형식·화풍 규칙은 `일본애니.md`, 공통 규칙은 `CLAUDE.md`.

- 한 줄: 사람이 모두 떠난 도시에서 300년 동안 혼자 공원을 고쳐 온 정비 로봇 앞에, 길 잃은 소녀가 나타난다.
- 반전: 그 공원은 300년 전 소녀의 고조할머니가 로봇에게 "언젠가 아이들이 돌아오면 놀 곳을 지켜 줘"라고 부탁한 곳
- 나레이션: **남자 성우 4**(M4, 정상 속도, 톤 -1.5)가 대사까지 모두 읽음 (사용자 결정 2026-10-31)
- 제목 후보: 「300년 동안 아무도 오지 않은 공원을 지킨 로봇, 마지막 명령의 진짜 뜻」 (N화 표시 없음)
- 인물: 보리(정비 로봇), 루미(10살), 도현(루미 아빠, 고철 수거단), 강철수(수거단 두목), 윤서(300년 전 기술자, 루미의 고조할머니)
- 만드는 법: `python 연재/마지막정비명령/마지막정비명령_단편.py job <그림폴더>` → klein_worker → 검수 → 점검표 → `... project <그림폴더>` → render_project --대본그대로
