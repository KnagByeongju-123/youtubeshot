# 화성의 오디세이 (블록 애니 · 소설 리뷰: 줄거리 + 해석 · 약 10분)
- 사용자 결정 2026-11-10: 유튜브 영화리뷰(엠터 채널)처럼 줄거리와 해석을 들려주는 형식을, 저작권이 끝난 고전 SF 단편으로. 블록 애니(`블록애니.md`)로 만듦.
  방식·길이는 사용자가 따로 말하지 않아 Claude 가 '줄거리 + 해석, 약 10분'으로 잡음 (바뀌면 이 줄을 고침)
- 원작: Stanley G. Weinbaum, "A Martian Odyssey" (Wonder Stories 1934년 7월호). 작가 1935-12-14 사망(33세, 폐암) → 한국에서 저작권 끝남.
  미국: 구텐베르크 #23731 ('저작권 갱신 기록을 찾지 못함'). 원문을 읽지 않고 줄거리를 우리말로 새로 씀
- 몰림 검사(2026-11-10): '와인바움 화성의 오디세이'·'화성 오디세이 1934 소설 트윌' — 한국어 영상 0개 (전체 기간).
  장르('SF 단편소설 리뷰')는 큰 채널(기묘한 밤)과 작은 채널이 많음 → 제목은 작품 이름 대신 줄거리 미끼로
- 해석 부분의 사실(출처: 영어 위키백과 A Martian Odyssey · Stanley G. Weinbaum, 2026-11-10 확인):
  작가의 첫 SF 발표작 / 발표 뒤 일 년 반이 못 되어 사망 / 1970년 미국 SF 작가 협회 투표 2위(1위 아시모프 「전설의 밤」) /
  아시모프 "독자들이 그에게 열광했다" / 화성에 그의 이름이 붙은 구덩이(크레이터)
- 단위: 원문 마일·피트·화씨를 미터법으로 (800마일≈1,300km, 하루 40마일≈64km, 75피트≈23m, 150피트≈46m, 6인치→10피트 = 15cm→3m, 화씨 영하 80도≈영하 62도)
- 뺀 것: 원문의 인종 비하 표현이 든 대목(낱말 이야기)은 다루지 않음
- 성우: 남자 성우 1 (M1, 정상 속도, 톤 -1.5)
- 인물(블록, `블록애니/화성인물.py`): 자비스(카키 탐사복·가죽 모자·고글·빨간 코·등에 물통), 해리슨(남색 제복·대장 모자·회색 콧수염),
  푸츠(풀빛 작업복·금발), 르루아(작은 키·흰 겉옷·검은 머리·콧수염), 팬시 롱(금발·빨간 옷, 환영으로만 나옴),
  트윌(청록 깃털 둥근 몸·긴 목·긴 부리·가는 다리·목에 검은 가방), 피라미드를 쌓는 것(은회색 비늘 통·팔 하나·입 하나·뾰족 꼬리),
  꿈을 보여 주는 것(땅 구멍 속 검은 밧줄 팔 여섯), 수레를 미는 것(통 몸·다리 넷·팔 넷·눈이 빙 둘러·북 같은 윗면) + 구릿빛 수레
- 캐릭터 시트: `캐릭터시트/<이름>_시트.png` (앞·옆·옆·뒤), 모음 `화성의오디세이_캐릭터시트_전체.jpg`. 대본: `대본.txt`
- 배경(사용자 결정 2026-11-10): 텅 비지 않게 — `블록애니.md` 의 '배경' 규칙. 화성 세트마다 절벽·바위·식물·모래 언덕·달 두 개·별, 굴 안은 기둥·전등·기계
- 만드는 법: 대본 `대본.txt` → 프로젝트 `화성의오디세이.json`(쉼표 넣음) → 녹음·검사 → `블록애니/시간표_만들기.py` →
  `블록애니/화성_장면.py all`(세트 S 우주·X 전시실·Y 전시실 끝·A 착륙지·B 추락 사막·C 만남·D 피라미드·E 운하·F 진흙 도시·G 굴 속 + 샷 127개 + `숫자.json`) →
  `blockbench_샷촬영.js … --test` 로 검수 → 전체 촬영(3개 동시, 약 9,300장·2시간) → `블록애니_조립.py`
- 카메라(사용자 요청 2026-11-10 "좀 더 역동적인 움직임"): 돌아 들어가기 `orbit()`, 따라가기 `follow`, 흔들림 `shake`(추락·싸움·불기둥), 낮은 곳에서 솟는 크레인.
