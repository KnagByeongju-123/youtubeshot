# 《엄마의 텃밭》 연재 기획 (서작가 에세이)

> 《두 번째 새벽》과는 별개의 연재. 다음 회차를 만들 때 이 파일과 `등장인물.json` 을 먼저 읽고 인물·말투·화풍을 그대로 이어 간다.
> 회차를 만들 때마다 아래 '회차 기록'에 한 줄 요약을 적는다.

## 형식
- 주제: 에세이. **한 화 = 서작가 에세이 한 편**을 약 10분 영상으로 만든다
- 가로 영상(1920×1080). 말풍선 없이 대사·나레이션은 화면 아래 자막. 컷마다 그림 한 장, 천천히 확대·이동
- 화면: 위 큰 제목 없음(처음 제목 카드만), 자막은 한 줄씩 차례로, 오른쪽 위 장면 설명 없음 (사용자 결정, CLAUDE.md 연재 영상 화면 규칙)
- **원문 문장은 그대로 살리고**, 10분을 채우려 그 사이에 장면 묘사·어린 시절 추억을 덧붙인다
  (덧붙인 추억은 Claude 가 지은 것 → 작가의 실제 추억을 받으면 그것으로 바꾼다)
- 나레이션은 **존댓말**(~습니다/~요, 사용자가 정함). 원문의 '~했다'체도 존댓말로 바꿔 읽음. 대사만 인물 말투
- 나레이션 = **여자 성우 F2 (Supertonic F2), 속도 -10%, 톤 -1반음** — 주인공 '나'의 목소리. 1인칭 에세이라 기본 규칙 '남자 성우 2' 대신 사용자가 정함
- 화풍: **파스텔 감성 일러스트** — 가는 갈색 연필 선, 투명 수채·색연필, 복숭아·민트·크림빛 낮은 채도, 따뜻한 빛 (프로그램 그림 스타일 이름 그대로)
- **'끝까지 보시면' 같은 유튜브식 예고 문장은 쓰지 않음** (사용자 결정, 에세이 분위기를 깸). 오프닝은 잔잔한 물음 한 줄로 끝냄
  (예: "엄마가 안 계신 그날이, 어떻게 엄마와 가장 가까운 날이 되었을까요.") → 프로그램이 오프닝을 고쳐 쓰지 않게 영상은 `render_project.py … --대본그대로`
- 자막 파일은 매화 영어·일본어 SRT + 영어·일본어 제목·설명란 (한국어는 영상에 박힌 자막)

## 제목
- **연재 제목: 《엄마의 텃밭》** — 후보 《아궁이 불빛 아래》·《그리운 것들은 다 고향에 있다》·《서작가의 사계절 편지》 중 사용자가 고름
- **회차 제목 형식: `엄마의 텃밭 N화 - 부제`**
- 외국어 이름: 영어 **Mom's Garden** (Ep. N), 일본어 **母の菜園** (第N話). 서작가 = Seo / ソ作家
- 유튜브 제목 형식: `<그 화의 마음을 담은 한 줄> | 엄마의 텃밭 N화` (예: 엄마가 떠나고 처음 맞은 생신, 아궁이 불꽃 속에 엄마가 있었다 | 엄마의 텃밭 1화)
- 외국어 자막: 이 서버에는 번역용 AI 키가 없어서 `영어_번역.transcribe_chunks` 로 자막 시간만 받고, 번역은 Claude 가 원래 대본을 보고 직접 함
- 1화 부제: **엄마 없는 첫 생신** (후보: 불꽃 속의 엄마 / 타닥타닥, 엄마 생각 / 그날, 엄마는 가장 가까이 있었다)

## 인물별 목소리 (등장인물.json 의 voice)
- 나(=나레이션) F2 -10% 톤-1 / 엄마 F1 -12% / 젊은 엄마 F1 -5% / 오빠 M2 -5% 톤+1 / 언니 F5 +5% / 어린 나 F2 +6% 톤+2 / 어린 오빠 M1 +6% 톤+1 / 어린 언니 F4 +6% 톤+1
- 오빠(M5)·엄마(F3 톤-1)는 처음 영상에서 '톤이 너무 낮다'고 해서 높인 후보 중 사용자가 고름

## 말투
- 대사는 **모두 표준말** (부산 사투리도 써 봤지만 성우 억양이 표준어라 어색해서 사용자가 표준말로 정함)
- 장이 끝날 때마다 다음 장 예고 한 문장은 **넣음** (사용자 결정: '잠시 뒤, 그 이야기를 들려 드릴게요' 등)

## 인물 (외모는 `등장인물.json`, 그림은 `캐릭터시트/`)
- **나** (50대 초반, 주인공·화자): 작고 마른 몸, 차분하고 조용함. 시집간 딸로 친정에 옴
- **엄마** (70대 후반, 돌아가시기 전) / **젊은 엄마** (회상 속 30대 후반, 1980년대 시골)
- **오빠** (60대 초반, 맏이): 고향을 지키며 텃밭·뒷밭 농사(배추·무, 단감·사과·석류). 크고 말수 적음
- **언니** (50대 후반): 통통한 체형(사용자 확인: 실제로도 통통함), 쾌활한 이야기꾼
- **어린 나 / 어린 오빠 / 어린 언니**: 회상 장면 (1980년대 시골)

## 썸네일
- 영상 그림과 같은 파스텔 화풍, **썸네일만 불빛 주황을 강하게** (어두운 배경 + 장작불). 썸네일 전용 그림을 klein 으로 따로 그림(인물 시트를 refs, 글씨 자리를 비우게)
- 글씨 얹기: `python 연재/서작가/썸네일_만들기.py <그림> <결과.jpg> "<1줄>" "<2줄>" <주황으로 강조할 낱말> <left|top|bottom> "엄마의 텃밭 N화" [sans|serif]`
  (흙빛 둥근 회차 띠. sans = 검은고딕, serif = 나눔명조 ExtraBold. 글꼴 fonts/BlackHanSans-Regular.ttf 는 파일 맨 위 주소에서 받음)
- **1화 최종 = 1번** (`1화_썸네일.jpg`): 왼쪽 '**불꽃** 속에 / 엄마가 있었다'(불꽃 주황), 오른쪽 아궁이 앞에서 우는 나 + 불꽃 속 엄마 얼굴. 유튜브 제목과 이어짐.
  다른 후보: 2번 불꽃 속에 선 엄마 + 나의 옆얼굴 '엄마, 보고 싶어요'(명조) / 3번 엄마 사진·미역국 '엄마 없는 첫 생신' / 4번 1번 그림 + '엄마 없는 첫 생신'(명조)

## 회차 기록
- **1화 엄마 없는 첫 생신** (10분 47초, 그림 40장, 2026-10-24 완성): 유튜브 제목 = **「엄마가 떠나고 처음 맞은 생신, 아궁이 불꽃 속에 엄마가 있었다 | 엄마의 텃밭 1화」**
  (영어: The First Birthday After Mom Was Gone, We Found Her in the Fire | Mom's Garden Ep. 1 / 일본어: 母が旅立って初めての誕生日、かまどの炎の中に母がいた｜母の菜園 第1話)
  줄거리: 엄마 없는 첫 생신에 친정 식구가 모임 → 작년 생신의 촛불·탄 미역국·업어 주던 등·비 오는 날 우산·소풍 김밥 → 텃밭의 배추와 무, 김장 → 뒷밭 감나무와 오빠의 어린 시절
  → 아랫방 아궁이의 시래기와 군고구마 → 불꽃 속 엄마, 끝내 흘린 눈물 → 마루의 밤하늘 "엄마, 생신 축하드려요"
  만들며 정한 것: 사투리 대신 표준말, 장 끝 예고 문장 넣음, '끝까지 보시면' 뺌, 화면 규칙(위 제목·장면 설명 없음, 자막 한 줄씩), 오빠·엄마 목소리 높임,
  나레이션 겹침('것만만')·빨라짐(짧은 문장) 검사 도구를 만들어 고침. 덧붙인 추억은 Claude 가 지은 것 → 작가의 실제 추억이 오면 바꿀 수 있음
