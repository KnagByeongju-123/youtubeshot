# 마지막 잎새 (나무 인형 · 말없는 감동 쇼츠 · 약 45초)
- 사용자 결정 2026-11-15: 오래되었지만 인기 있었던 이야기 중 「마지막 잎새」(오 헨리 1907, 저작권 끝남)를 **끝에서 역할이 바뀌게** 고쳐서, **나무 인형**으로.
  지난 편들과 같게 — 약 45초, **나레이션·화면 글자 없음**, 세로 1080×1920, 24fps, 쇼츠만
- 원작 줄거리를 빌려 오되 인물·생김새·장소는 새로 디자인 (특정 영화·애니 모습을 따르지 않음). 원작과 달리 할아버지는 살아 있음 → 세월이 흐른 뒤 역할이 뒤바뀜
- 인물(나무 인형, `블록애니/잎새인물.py`):
  - 꼬마 소녀: 하늘색 잠옷(긴 소매·긴 바지), 갈색 양갈래 머리 + **노란 리본**, 흰 실내화
  - 화가 할아버지: 남색 베레모, 흰 수염, 크림색 셔츠, **물감 묻은 갈색 앞치마**, 회색 바지
  - 어른 소녀: 같은 갈색 머리 하나로 묶음 + **어릴 때와 같은 노란 리본**, 초록 스웨터, 갈색 긴 치마, 물감 앞치마(할아버지처럼 화가가 됨)
  - 늙은 할아버지: 흰머리·흰 수염, 같은 베레모, 하늘색 잠옷(침대) — 처음 소녀 자리에 누움
- 소품: 담쟁이 벽(창밖 벽돌 벽 + 줄기 + 잎들), 그려진 잎(벽에 붙은 납작한 초록 잎), 사다리, 등불, 붓, 침대·이불, 창문
- 처음과 끝이 뒤집혀 돌아오는 구조: 처음엔 **소녀가 누워** 떨어지는 잎을 보고 할아버지가 밤에 잎을 그려 줌 → 끝엔 **할아버지가 누워** 있고 어른이 된 소녀가 잎을 그려 줌.
  마지막 그림: 벽에 **옛날 그린 잎과 새로 그린 잎이 나란히**

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–6 | 겨울 창가 (흐림) | 침대에 누운 소녀가 창밖 벽돌 벽을 봄. 담쟁이 잎이 바람에 하나 떨어지고 몇 장 안 남음 |
| 6–11 | 걱정 | 할아버지가 방문가에서 소녀를 보고, 창밖 잎을 올려다봄 |
| 11–19 | 비바람 밤 | 할아버지가 등불을 놓고 사다리에 올라 벽에 붓으로 잎을 그림. 마지막 진짜 잎이 날아감 |
| 19–24 | 아침 | 벽에 잎 하나가 그대로. 소녀가 천천히 일어나 창가로 와서 바라봄 / 아래에서 흠뻑 젖은 할아버지가 재채기 |
| 24–29 | 봄 | 건강해진 소녀와 할아버지가 그 벽 앞에. 할아버지가 소녀 손에 붓을 쥐여 줌 → 둘이 함께 그림을 그림 |
| 29–33 | 세월 | 같은 벽, 담쟁이가 여름→가을→겨울로 바뀜. 그려진 잎만 늘 그대로 |
| 33–38 | 다시 겨울 (뒤바뀜) | 이번엔 늙은 할아버지가 침대에 누워 창밖을 봄. 잎이 떨어짐 |
| 38–45 | 밤 → 아침 | 어른 소녀가 사다리에 올라 붓으로 옛 잎 옆에 새 잎을 그림 → 아침, 할아버지가 창밖의 두 잎을 보고 웃음. 천천히 어두워짐 |

- 음악: 쓸쓸한 오르골(겨울) → 비바람·천둥(밤, 음악 작게) → 아침 따뜻한 패드 → 봄 밝은 오르골 → 세월 짧은 이음 → 다시 쓸쓸 → 끝에 따뜻하게
