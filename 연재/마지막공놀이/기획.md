# 마지막 공놀이 (블록 애니 · 말없는 감동 쇼츠 · 약 45초)
- 사용자 결정 2026-11-11: 강아지 주제 추천 5번 '마지막 공놀이'. 지난 편들과 같게 — 약 45초, **나레이션·화면 글자 없음**, 세로 1080×1920, 24fps, 쇼츠만
- 인물(블록, `블록애니/밥그릇인물.py`): 꼬마(빨간 모자·노란 옷), 어른(같은 빨간 모자·노란 후드·청바지), 어린 강아지, 늙은 강아지(얼굴·등 털이 하얗게 셈), 빨간 공
- 처음과 끝: 처음엔 공을 **멀리 던지고** 강아지가 뛰어가 물어 옴 → 끝엔 공을 강아지 코앞에 **살짝 굴려 줌**

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–8 | 공원 언덕 (아침) | 꼬마가 공을 멀리 던짐 → 어린 강아지가 신나게 달려가 물고 옴 → 꼬마가 쓰다듬음 |
| 8–14 | 날마다 | 하늘이 바뀌며 몇 번 더: 던지기·달리기·물어 오기, 꼬리 흔들기 |
| 14–18 | 세월 | 같은 나무 아래 놓인 빨간 공, 나뭇잎이 봄·여름·가을·겨울로 바뀜 |
| 18–25 | 어른 | 어른이 공을 던짐 → 늙은 강아지가 천천히 따라가다 중간에 멈춰 엎드림 |
| 25–31 | 다가감 | 어른이 공을 주워 와 강아지 옆에 앉아 쓰다듬음 |
| 31–37 | 살짝 굴리기 | 어른이 공을 강아지 코앞에 살짝 굴려 줌 → 강아지가 코로 툭 밀고 꼬리를 흔듦 |
| 37–45 | 노을 | 둘이 언덕에 나란히 누워 노을을 봄, 카메라가 천천히 멀어짐 |

- 음악: 밝은 오르골 → 세월 장면 조금 커짐 → 잔잔한 슬픈 오르골 → 꼬리를 흔들 때 따뜻하게 → 노을에서 조용히 끝
