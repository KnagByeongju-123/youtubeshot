- 허구 단편이라 몰림 검사는 하지 않음. 녹음·받아쓰기 검사 없음
- 인물(블록, `블록애니/우산인물.py`): 할아버지(회색 머리·갈색 조끼·베이지 바지), 늙은 할아버지(흰머리·같은 조끼·굽은 허리·지팡이),
  꼬마 손녀(분홍 우비·노란 장화·양갈래 머리), 어른 손녀(긴 머리 묶음·남색 코트·**어릴 때와 같은 분홍** 목도리), 파란 우산(펼친·접은), 노란 버스, 정류장 표지판·벤치
- 처음과 끝이 뒤집혀 돌아오는 구조: 처음엔 할아버지가 우산을 손녀 쪽으로 기울여 **할아버지 어깨가 젖고**, 끝엔 손녀가 할아버지 쪽으로 기울여 **손녀 어깨가 젖음**

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–5 | 비 오는 정류장 | 꼬마 손녀가 혼자 비를 맞으며 버스를 기다림 → 할아버지가 파란 우산을 들고 서둘러 와서 씌워 줌 |
| 5–11 | 우산 하나 | 할아버지가 우산을 손녀 쪽으로 기울임 → 할아버지 한쪽 어깨가 젖음(짙은 색) |
| 11–17 | 버스 | 노란 버스가 옴 → 손녀가 타며 손을 흔듦 → 할아버지가 우산 쓴 채 배웅 |
| 17–22 | 세월 | 현관 옆에 세워 둔 접은 파란 우산. 하늘·나무 색이 봄→여름→가을→겨울로 빠르게 몇 번 바뀜 |
| 22–27 | 다시 비 오는 정류장 | 허리 굽은 할아버지가 지팡이를 짚고 혼자 비를 맞으며 서 있음 |
| 27–32 | 우산 | 어른이 된 손녀가 같은 파란 우산을 들고 뛰어와 씌워 줌, 할아버지 쪽으로 기울여 손녀 어깨가 젖음 |
| 32–38 | 알아봄 | 할아버지가 고개를 들어 손녀를 봄 → 손녀가 웃으며 할아버지 손을 잡음 |
| 38–45 | 함께 | 우산 하나를 쓰고 천천히 걸어가는 뒷모습(손녀 어깨 젖은 자국) → 비가 그치고 하늘이 갬 |

- 음악: 빗소리 + 잔잔한 오르골 → 세월 장면에서 조금 커짐 → 다시 비, 작게 → 손을 잡을 때 따뜻하게 → 비 그치며 밝게 끝
