# 서툰 아빠의 머리 묶기 (블록 애니 · 말없는 감동 쇼츠 · 약 45초)
- 사용자 결정 2026-11-13: 감동 이야기 추천(노인 제외) 4번 '서툰 아빠의 머리 묶기'. 지난 편들과 같게 — 약 45초,
  **나레이션·화면 글자 없음**, 세로 1080×1920, 24fps, 쇼츠만. 허구 단편이라 몰림 검사 안 함
- 벤치마킹: 아빠와 딸·서툴러도 애쓰는 마음 공식 — 이야기·인물은 새로 지음
- 인물(블록, `블록애니/머리묶기인물.py`):
  · 딸 소은(6살쯤): 노란 원피스·흰 타이츠·분홍 신발, 긴 검은 머리 — 머리 모양 3가지(풀린 머리 / 아빠가 엉망으로 묶은 삐뚤어진 꽁지 / 예쁜 양갈래 + 빨간 리본)
  · 아빠: 흰 셔츠·남색 넥타이·회색 바지·검은 구두, 짧은 검은 머리 — 끝에 딸이 꽂아 준 빨간 리본
  · 연습용 털실 인형: 작은 천 인형(하늘색 옷), 갈색 털실 머리 — 엉킨 머리 / 예쁜 양갈래
- 장소(세트 하나): 집 — 현관 옆 거울과 작은 의자(아침), 식탁과 스탠드(밤), 현관문 밖 골목
- 처음과 끝: 처음엔 **엉망인 머리로 울상** → 끝엔 **예쁜 양갈래로 웃고, 아빠 머리에도 리본**

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–7 | 아침 거울 앞 | 의자에 앉은 딸 뒤에서 아빠가 빗질·묶기(손이 허둥지둥) → 삐뚤어진 꽁지, 삐죽 튀어나온 머리카락. 거울을 본 딸이 고개를 푹 숙임 |
| 7–12 | 현관 | 딸이 두 손으로 머리를 가리고 나감. 아빠가 문가에서 미안한 듯 머리를 긁적임 |
| 12–22 | 밤 식탁 | 스탠드 불빛 아래 아빠가 털실 인형 머리로 연습 — 엉킴 → 풀고 다시 → 창밖 달이 기울고 → 인형 머리가 예쁜 양갈래가 됨, 아빠가 주먹을 꼭 쥠 |
| 22–30 | 다음 날 아침 거울 앞 | 아빠 손이 차분하게 움직임 → 예쁜 양갈래 + 빨간 리본. 딸이 거울을 보고 깡충 뛰고 아빠에게 안김 |
| 30–37 | 리본 하나 | 딸이 리본 하나를 빼 들고, 아빠가 몸을 숙이자 짧은 머리에 리본을 꽂아 줌 |
| 37–45 | 함께 나감 | 둘이 손잡고 현관을 나섬 — 딸의 양갈래와 아빠 머리의 리본이 함께 흔들림. 카메라가 멀어지며 끝 |

- 음악: 장난스러운 오르골(허둥지둥) → 울상일 때 작아짐 → 밤에는 잔잔한 패드·째깍 소리 → 성공할 때 따뜻하게 → 아침 깡충에 밝게 → 리본에서 가장 따뜻하게 끝.
  효과음: 빗질 소리, 고무줄 튕기는 소리, 시계 째깍, 문 여닫는 소리, 새소리
- 썸네일: 영상을 다 만든 뒤 Claude 가 후보를 보고 정함
