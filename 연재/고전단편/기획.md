# 고전 단편 원문 낭독 (채널: 드림노트)

> 사용자 결정 2026-10-31: 역사 채널 '진짜 역사 기록관'은 **드림노트**로 이름을 바꾸고 자유로운 콘텐츠로.
> 그 첫 연재로 저작권이 끝난 한국·일본·중국 단편소설(잡지·신문에 실렸던 것)을 **원문 낭독 + 수묵 담채 그림**으로.

## 저작권 기준 (필수)
- 작가가 **1962년 이전에 사망** (한국: 그해까지 죽은 작가의 작품은 공유 저작물) **그리고 1930년 이전 발표** (미국에서도 공유 저작물)
- 번역문은 따로 저작권 → 일본·중국 작품은 남의 한국어 번역을 쓰지 않고 원문을 직접 옮김
- 한국 작품은 원문 그대로, 맞춤법만 지금 표기로. 원문 출처: 위키문헌(ko.wikisource.org, PD-old 표시 확인)

## 만드는 법
- 대본 = 작가·시대 소개 30초 + 원문 전체 + 끝인사. 긴 문단은 문장 끝에서 나눔(그림이 문단마다 바뀜)
- 그림: `그림: 근대 수묵 담채`(1920~30년대 경성) — 일본·중국 작품은 그 시대·나라에 맞는 수묵 담채
- 인물 시트(앞·옆·옆·뒤 4장)를 먼저 그려 사용자 확인 → 장면
- 나머지(나레이션 M4·쉼표, 나레이션 먼저 → 그림 → 점검표 → 영상, 24fps·제목 숨김)는 CLAUDE.md 그대로
- 배경음: 한국 작품은 한국 전통(가야금·해금) 계면조처럼 이야기 분위기에 맞춰

2. 아쿠타가와 류노스케 「라쇼몽」 (1915)
