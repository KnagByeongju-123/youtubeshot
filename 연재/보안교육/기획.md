# 정보보안 교육 영상 기획

> 사용자 회사의 '정보보안 서약서'(통합업무시스템·PC·네트워크 사용 서약)를 바탕으로 만든 사내 교육 영상. 다시 만들거나 고칠 때 이 파일과 `등장인물.json` 을 먼저 읽는다.

## 정한 것 (사용자 결정)
- 길이 약 5분, 서약서 1~8번 → 관리자 추가 서약 → 위반 시 책임 → 마무리 순서. 그림 27장
- 그림: 밝은 사무실 웹툰풍 (프로그램 그림 스타일 '웹툰')
- 회사·고객사 이름은 넣지 않고 '우리 회사'
- 회사 메일이 따로 없음 → '개인 메일' 대신 '메일로 보내기', 보낼 일이 있으면 먼저 승인
- 인물: 신입 사원 민수, 보안 담당 박 팀장 (+ c08 에만 나오는 옆자리 선배, 시트 없음)
- 목소리: 나레이션 M2 / 민수 M1 +5% 톤+1 / 박 팀장 F1 -5% 톤-1 / 선배 M3 -3% 톤-1 (샘플 1번씩 고름)

## 만드는 법
- `python 연재/보안교육/정보보안_서약.py job <폴더>` → klein_worker 로 그림 → `... project <폴더>`
- `render_project.py 연재/보안교육/정보보안_서약.json --대본그대로 --길이고정`
- 만들며 고친 것: '모든 것이 설레기만 합니다' 가 빨라짐·겹침으로 계속 걸려 '모든 것이 새롭고 설레요' 로 바꿈. 읽기사전에 USB=유에스비, PC=피씨
