1. 서버 확인: `nproc`, `free -g`, `grep -c amx_bf16 /proc/cpuinfo` — CPU 가 많을수록 빠름 (4개면 2분 구간 하나에 약 25분)
2. 프로젝트 파일: `.supertonic_venv/bin/python 연재/걷는모아이/모아이_단편.py project` → `.supertonic_venv/bin/python -X utf8 나레이션_쉼표.py 연재/걷는모아이/모아이_단편.json`
3. 녹음: `xvfb-run -a .supertonic_venv/bin/python -X utf8 나레이션_배경음만.py 연재/걷는모아이/모아이_단편.json output/걷는모아이/모아이_나레이션만.mp3 --배경음배율 0`
4. 검사 ①: `.sd_venv/bin/python -X utf8 나레이션_겹침검사.py output/걷는모아이/모아이_나레이션만.mp3 연재/걷는모아이/모아이_단편.json --고치기 연재/걷는모아이/모아이_단편.json`
   검사 ②: `output/tts_cache/나레이션검증.json` 의 이 편 문단 점수 확인 → `output/걷는모아이/모아이_나레이션검증.txt`
5. 장면 그림 다시 만들기: `.supertonic_venv/bin/python 연재/걷는모아이/장면3D_설정.py` → 검수 `.supertonic_venv/bin/python 입체애니_검수.py 연재/걷는모아이/장면3D`
6. 영상은 **2분 구간씩**: `render_project.py 연재/걷는모아이/모아이_단편.json --대본그대로 --길이고정` 을 돌리고, 로그에 '구간 2/' 가 나오면 멈춤 →
   `output/장문/_작업_모아이는 어떻게 걸었을까/영상구간/seg_000.mp4` 에 나레이션 mp3 를 붙여 사용자에게 보냄 → 확인 뒤 다음 구간
