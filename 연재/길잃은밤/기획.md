# 길 잃은 밤 (나무 인형 · 말없는 감동 쇼츠 · 약 45초)
- 사용자 결정 2026-11-12: 강아지 주제 추천 1번 '길 잃은 밤'. 지난 편들과 같게 — 약 45초, **나레이션·화면 글자 없음**, 세로 1080×1920, 24fps, 쇼츠만
- 인물(확인한 시트 그대로, `연재/나무인형/캐릭터시트/`): 나무 소년, 나무 강아지(빨간 바퀴 넷 — 이 이야기에선 살아 움직이는 친구), 목수 할아버지(등불을 듦)
- 줄(목줄): 소년 오른손 ↔ 강아지 목걸이, 처음부터 끝까지 이어져 있음 (촬영 때 두 점 사이로 늘려 붙임, 세트정보.json 의 ropes)
- 처음과 끝: 처음엔 **소년이 앞장서 줄을 끌고** 강아지가 덜컹거리며 끌려옴 → 끝엔 **강아지가 앞장서 줄을 당기고** 소년이 뒤따라감 (같은 옆모습 카메라로 뒤바뀜이 보이게)

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–5 | 낮 숲길 | 소년이 줄을 쥐고 앞장서 신나게 걸음, 강아지가 뒤에서 끌려옴 (옆모습) |
| 5–10 | 더 깊이 | 소년이 뛰어감. 강아지 바퀴가 나무뿌리에 걸려 덜컹 튀어 오름, 소년은 모르고 계속 |
| 10–15 | 해 질 녘 갈림길 | 하늘이 주황·보라. 소년이 멈춰 이쪽저쪽 두리번 — 길을 잃음 |
| 15–22 | 밤, 큰 나무 아래 | 소년이 주저앉아 무릎을 끌어안고 웅크림(어깨 들썩). 강아지가 다가와 머리를 무릎에 비빔 |
| 22–27 | 불빛 | 강아지가 고개를 번쩍 들고 먼 곳을 봄 → 나무 사이로 작은 노란 불빛 |
| 27–33 | 강아지가 이끔 | 강아지가 줄을 당기며 앞장, 소년이 일어나 뒤따라감 (처음과 같은 옆모습, 순서만 반대) |
| 33–38 | 숲 끝 | 숲을 나오자 불 켜진 공방, 문 앞에서 등불을 든 할아버지 |
| 38–42 | 안아 줌 | 할아버지가 몸을 숙여 소년을 안아 줌, 강아지 꼬리가 흔들림 |
| 42–45 | 집으로 | 할아버지가 강아지 머리를 쓰다듬고, 셋이 불 켜진 문 안으로 (뒷모습) → 어두워짐 |

- 음악: 밝은 오르골(숲길) → 해 질 녘 느려지고 작아짐 → 밤은 쓸쓸한 패드 + 귀뚜라미 → 불빛을 볼 때 오르골 한 소절 → 걸어갈 때 따뜻하게 → 할아버지 품에서 가장 따뜻하게
- 효과음: 바퀴 덜컹(나무 톡), 부엉이 한 번(밤), 문 여는 소리 정도
