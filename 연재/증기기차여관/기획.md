# 철길 끝 증기 기차 여관의 마지막 손님 (블록 애니 · 스팀펑크 단편)
- 형식: 블록 애니(Blockbench), 오리지널 스팀펑크 단편 약 8분, 24fps 가로, 자막 한 줄씩, 배경음 오르골 (사용자 결정 2026-11-10: '증기 기차 여관', 약 10분)
- 나레이션: Supertonic M1, 쉼표 넣기·겹침 검사·받아쓰기 검사 통과 ('오웬'이 '오엔'처럼 받아 적힌 곳 2군데)
- 인물: 오웬(70, 여관 주인, 놋쇠 고글) · 레나(젊은 기관사, 가죽 외투·빨간 목도리) · 그림스(철도 회사 감독관, 실크햇) · 톡(주전자만 한 증기 로봇) · 마리(오웬의 아내, 회상)
- 탈것: 증기 기관차 + 여관 객차 3칸, **그림스의 걷는 증기차**(사용자 요청 2026-11-10: 구조가 복잡한 걷는 증기차 — 쇠다리 넷·관절·피스톤·톱니), 증기 비행선
- 세트: A 사막 종착역(오늘·회상·폭풍 밤·출발) / B 객차 안 / C 기관실 / D 협곡 철교 / E 바닷가 마지막 역(등대·비행선)
- 만드는 법: `블록애니/증기_시트.py` → `증기_장면.py` → `증기_샷.py` → `blockbench_샷촬영.js` → `블록애니_조립.py`
