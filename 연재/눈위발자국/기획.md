# 눈 위 발자국 (블록 애니 · 말없는 감동 쇼츠 · 약 45초)
- 사용자 결정 2026-11-12: 추천 1번 '눈 위 발자국'. 지난 편들과 같게 — 약 45초, **나레이션·화면 글자 없음**, 세로 1080×1920, 24fps, **쇼츠만**
- 허구 단편이라 몰림 검사는 하지 않음. 녹음·받아쓰기 검사 없음
- 인물(블록, `블록애니/발자국인물.py`): 아빠(짧은 갈색 머리·회색 겨울 코트·**초록 목도리**·검은 장화),
  늙은 아빠(흰머리·**같은 초록 목도리**·같은 회색 코트·굽은 허리·지팡이), 꼬마 아들(**빨간 털모자+흰 방울**·노란 패딩·파란 장갑·빨간 장화),
  어른 아들(**어릴 때와 같은 빨간 털모자**·남색 패딩·청바지·갈색 장화), 발자국(큰 것·작은 것), 장소: 눈 덮인 마을 길 + 길가 큰 나무 + 작은 집
- 처음과 끝이 뒤집혀 돌아오는 구조: 처음엔 **아빠가 앞에서 보폭을 좁혀 발자국을 만들고 꼬마가 그 발자국을 밟으며** 따라감 →
  끝엔 **어른 아들이 앞에서 보폭을 좁혀 걷고 늙은 아빠가 그 발자국을 밟으며** 따라옴

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–5 | 눈 오는 아침 | 작은 집 문이 열리고 아빠와 꼬마가 나옴. 길에는 아무 발자국 없는 새하얀 눈 |
| 5–12 | 발자국 따라가기 | 아빠가 앞서 걸으며 뒤를 돌아보고 일부러 보폭을 좁힘 → 꼬마가 아빠 발자국에 콩콩 뛰어 쏙쏙 밟음 |
| 12–17 | 큰 발자국 속 작은 장화 | 가까이: 큰 발자국 안에 작은 빨간 장화가 쏙 들어감 → 꼬마가 웃고 아빠가 고개를 끄덕임, 둘이 큰 나무 쪽으로 걸어감 |
| 17–22 | 세월 | 같은 길가 큰 나무. 봄 꽃 → 여름 초록 → 가을 단풍 → 다시 겨울 눈으로 빠르게 바뀜 |
| 22–27 | 다시 눈 오는 날 | 같은 집 앞. 어른이 된 아들이 앞서 나오고, 허리 굽은 아빠가 지팡이를 짚고 미끄러운 눈길 앞에서 머뭇거림 |
| 27–33 | 이번엔 아들이 | 아들이 뒤돌아보고 보폭을 좁혀 눈을 꾹꾹 다지며 걸음 → 아빠가 그 발자국을 하나씩 밟으며 따라옴 |
| 33–39 | 알아봄 | 아빠가 발자국을 내려다보고 멈춤 → 고개를 들어 아들을 봄 → 작게 콩 하고 발자국에 뛰어 밟음(어릴 때 아들처럼), 둘이 웃음 |
| 39–45 | 함께 | 위에서 내려다본 눈길: 한 줄 발자국 위에 겹친 두 발자국 → 둘이 큰 나무 쪽으로 천천히 걸어가고 눈이 계속 내림 → 어두워짐 |

- 음악: 눈 오는 바람 소리 + 잔잔한 오르골 → 콩콩 밟는 효과음(뽀드득) → 세월 장면에서 조금 커짐 → 다시 조용히 → 아빠가 콩 뛸 때 따뜻하게 → 부드럽게 끝
