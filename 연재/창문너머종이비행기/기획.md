# 창문 너머 종이비행기 (블록 애니 · 말없는 감동 쇼츠 · 약 45초)
- 사용자 결정 2026-11-13: 감동 이야기 추천(노인 제외) 2번 '창문 너머 종이비행기'. 지난 편들과 같게 — 약 45초,
  **나레이션·화면 글자 없음**(종이 그림에도 글자 없음), 세로 1080×1920, 24fps, 쇼츠만. 허구 단편이라 몰림 검사 안 함
- 인물(블록, `블록애니/종이비행기인물.py`):
  · 도윤(병실 아이): 하늘색 줄무늬 환자복(긴팔·긴바지)·노란 털모자·흰 실내화 → 퇴원 날엔 같은 털모자 + 남색 후드티·회색 바지·흰 운동화·빨간 가방
  · 하은(밖의 아이): 주황 티·청 반바지·갈색 양갈래(노란 머리끈)·흰 운동화
  · 새 아이(마지막 창가): 분홍 줄무늬 환자복·하늘색 털모자·어깨까지 오는 검은 머리
  · 처음에 함께 노는 친구 둘: 《같이 들어온 결승선》의 빨강·보라 아이 모형을 그대로 씀
- 소품: 하얀 종이비행기(계단식 세모 날개), 그림 그린 종이(해와 웃는 얼굴 — 글자 없음), 창가 선반에 쌓이는 종이비행기
- 장소(세트 하나): 병원 **3층** 병실(침대·창가 선반·열린 창문) — 사용자 결정 2026-11-13: 3층 창에서 날림(1층은 걸어가서 건네면 돼 날릴 까닭이 없어 보임) + 창밖 마당(잔디·나무·벤치·길·병원 현관문)
- 처음과 끝: 처음엔 **창 안의 도윤이 밖을 바라보기만** → 끝엔 **밖에 선 도윤이 창 안의 새 아이에게 종이비행기를 날림**

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–6 | 병실 창가 (흐린 낮) | 침대에 앉은 도윤의 뒷모습, 창밖에서 하은과 친구들이 공놀이. 친구들은 떠나고 하은이 창 쪽을 봄 |
| 6–10 | 첫 비행기 | 하은이 종이를 접어 날림 → 창으로 날아 들어가 도윤 무릎에 떨어짐 |
| 10–12 | 펼쳐 봄 | 도윤이 종이를 펼쳐 듦 — 해와 웃는 얼굴 그림 |
| 12–19 | 답장 | 도윤이 그림을 그려 접어서 창밖으로 날림 → 하은이 받아 펼쳐 들고 깡충, 손을 흔듦 |
| 19–27 | 날마다 | 아침·노을·눈 오는 날·봄: 비행기가 오가고, 창가 선반에 종이비행기가 하나둘 쌓임 |
| 27–33 | 퇴원 날 | 병원 문이 열리고 가방을 멘 도윤이 나옴 → 기다리던 하은과 처음 마주 섬, 손바닥 마주치기 |
| 33–38 | 돌아봄 | 둘이 마당 길을 걷다 도윤이 멈춰 병실 창을 돌아봄 → 창가에 새 아이가 혼자 밖을 봄 (처음 도윤과 같은 구도) |
| 38–45 | 이어 줌 | 도윤이 종이비행기를 날림 → 창 안 새 아이 손에 → 새 아이가 비행기를 들고 손을 흔듦, 둘도 흔듦. 카메라가 멀어지며 끝 |

- 음악: 쓸쓸한 오르골(창가) → 비행기가 날아들 때 밝게 → 날마다 따뜻하게 → 퇴원 날 가장 밝게 → 새 아이를 볼 때 잠깐 조용 → 비행기를 날릴 때 다시 따뜻하게 끝.
  효과음: 공 튀는 소리, 종이 접는 소리, 비행기 바람 소리, 문 열리는 소리, 손뼉(마주치기), 새소리
- 썸네일 후보: 창으로 날아드는 종이비행기(9초), 창가에 쌓인 비행기(25초), 마지막 비행기와 창가의 새 아이(40초)
