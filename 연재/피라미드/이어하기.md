## 남은 일
1. 새 서버 준비: `uv venv -p /usr/bin/python3.11 .bl_venv && uv pip install -p .bl_venv/bin/python "bpy==4.2.*" numpy pillow`
2. 영상 만들기 (조각이 있으면 이어서, 없으면 처음부터):
   ```
   BL_PIXEL=4 SEG_SEC=20 BLOCK_RENDER=blender RENDER_PAR=2 nohup xvfb-run -a .supertonic_venv/bin/python -u -X utf8 render_project.py 연재/피라미드/피라미드_단편.json --대본그대로 --길이고정 > output/피라미드/영상.log 2>&1 &
   ```
   - CPU 가 많으면 `RENDER_PAR` 를 (CPU 수 ÷ 2) 로
   - **첫 조각이 끝나면 한 장을 꺼내 Blender 그림(그림자·픽셀 무늬)인지 확인** — 20초 조각이 2분 만에 끝나면 옛 엔진으로 그려진 것 → 멈추고 그 seg 지우고 다시
   - 로그에 'Blender 일꾼이 꺼짐' 이 나오면 일꾼이 죽은 것 (`/tmp/_bl_worker_*.log`)
3. 완성 mp4 를 사용자에게 보냄 (`output/장문/<번호>_피라미드는 어떻게 쌓았을까/`)
4. (사용자가 원하면) 썸네일·업로드 문구 — 모아이 편과 같은 방식(`연재/걷는모아이/썸네일_만들기.py`, `_업로드문구.txt` 태그 칸 필수)
