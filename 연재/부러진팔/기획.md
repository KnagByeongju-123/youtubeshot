# 부러진 팔 (나무 인형 · 말없는 감동 쇼츠 · 약 45초)
- 사용자 결정 2026-11-11: 추천 3번 '부러진 팔' (마음이 찡한 감동). 지난 편들과 같게 — 약 45초, **나레이션·화면 글자 없음**, 세로 1080×1920, 24fps, 쇼츠만
- 인물: 나무 인형(`블록애니/나무인형.py`, 원통·공 모양, 팔·다리는 블록처럼 통째로 흔들림) — 나무 소년(세이지 셔츠)·나무 소녀(산호색 원피스)·목수 할아버지
- 핵심 그림: 끝에 **두 아이 팔이 바뀌어 있음** — 소녀 왼팔은 소년이 준 초록 소매, 소년 오른팔은 할아버지가 고친 소녀의 산호색 소매. 짝짝이 팔로 손잡고 걸어감

## 장면표
| 초 | 장면 | 보여 줄 것 |
|---|---|---|
| 0–6 | 마당 | 소년·소녀가 잡기 놀이로 뛰어다님 |
| 6–9 | 넘어짐 | 소녀가 넘어지며 왼팔이 빠져 두 동강으로 굴러감 |
| 9–15 | 나무 아래 | 소녀가 부러진 팔을 안고 웅크려 울음(어깨 들썩). 소년이 바라보다 공방 쪽으로 감 |
| 15–22 | 밤 공방 | 달빛 창가 작업대, 소년이 자기 오른팔을 붙잡고 떼어 냄 |
| 22–28 | 다음 날 | 한 팔인 소년이 비틀거리며 와서 초록 팔을 내밂 → 소녀 어깨에 초록 팔 |
| 28–33 | 다시 놀이 | 한 팔이라 균형을 잃는 소년을 소녀가 초록 팔로 붙잡아 줌 / 공방 문가에서 할아버지가 지켜봄 |
| 33–38 | 공방 | 할아버지가 작업대에서 소녀의 부러진 팔을 맞붙여 고침 |
| 38–45 | 함께 | 할아버지가 고친 산호색 팔을 소년에게 달아 줌 → 셋이 손잡고 노을 쪽으로 걸어감(뒷모습) |

- 음악: 밝은 오르골(놀이) → 넘어지는 순간 멈춤 → 슬픈 오르골 → 밤 공방은 아주 작게 → 팔을 건넬 때 따뜻하게 → 끝에 밝게
