# 조선 궁궐 복식 그림 기준 (2026-10-31)

출처: YTN 사이언스 「궁궐 복식에서 조선의 패션을 보다」(https://youtu.be/qYun4800cfI) 자막·화면 분석,
사용자가 준 기준 그림 `_기준/궁궐복식_기준.png`(정면 6인)·`_기준/궁궐복식_3면도.png`(앞·옆·뒤).
그림 모델은 한국 옷 이름을 몰라서 중국·일본 옷으로 그림 → 모양을 말로 풀어 쓰고(`캐릭터시트_만들기.py` 의 KO_COSTUME) 기준 그림을 refs 로 넣음.

| 항목 | 모양 (그림 주문에 쓰는 말) |
|---|---|
| 익선관 (왕) | 챙 없는 검은 두 단 모자(앞 낮고 뒤 높음), 뒤에 매미 날개 모양 날개 두 개가 **하늘로 솟음** |
| 사모 (관리·내관) | 같은 두 단 모자, 뒤 아래쪽에 납작한 주걱 모양 날개 두 개가 **양옆으로 수평** (챙 아님) |
| 곤룡포 (왕) | 대홍색, 둥근 깃(안에 흰 동정), 오조룡(발톱 다섯 용) 둥근 보가 가슴·등·양어깨 네 곳, 옥대(붉은 틀에 흰 옥 장식, 허리에 느슨하게 걸침), 흑화. 태조는 청색 곤룡포 |
| 단령 (관리) | 둥근 깃, 옆에서 끈으로 여밈. 색은 품계에 따라(높은 품계 붉은색, 낮으면 청·흑). 4품 이상 홍단령, 5품 이하 흑단령 |
| 흉배 | 가슴·등에 네모난 수놓은 판. 문관 = 날짐승(구름 속 흰 학 한 쌍), 무관 = 길짐승(호랑이·표범). 왕은 흉배 대신 둥근 '보' |
| 면류관·면복 (왕의 최고 예복) | 위에 앞으로 살짝 숙인 검은 평천판, 앞뒤로 구슬 줄 9줄(황제 12), 귀 옆 구슬(충). 구장복(검푸른 겉옷에 아홉 무늬), 붉은 치마, 폐슬·패옥·후수 |
| 적의 (왕비 대례복) | 왕비 대홍색·세자빈 아청색(대한제국 황후 청색 12줄). 꿩 무늬가 가로줄로, 둥근 용 보, 대수머리와 함께 |
| 원삼 | 소매가 아주 넓고 노랑·빨강·파랑 색동, 끝에 흰 한삼. 왕비 홍색, 빈·후궁 자색·녹색 |
| 당의 | 엉덩이를 덮는 저고리, 옆이 트이고 앞뒤 자락이 둥글게 내려옴, 금박. 왕실은 가슴·어깨에 둥근 보 |
| 궁녀·상궁 | 짧은 저고리(흰 동정, 긴 고름), 가슴께부터 풍성한 치마. 궁녀는 남치마, 왕비·대비는 자적 치마 |
| 머리 | 대수머리(적의와 함께, 위가 좁고 아래가 넓은 큰 가체), 어여머리(머리 위 둥근 큰 땋은 가체), 첩지(가르마에 얹는 장식: 왕비 용·봉황, 아래 품계 개구리) |
| 흑화 | 검은 목 긴 신, 두툼한 흰 밑창, 앞코가 살짝 들림 |
| 군사 | 전립(챙 넓은 검은 벙거지 + 붉은 술·깃), 동달이·전복, 무관 철릭·갑옷 |
