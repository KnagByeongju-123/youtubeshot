# 가야금 찬송가 연주 (수면·기도용 긴 영상)

## 진행 상황
- 1편 (6곡, 35분): 업로드 완료 (2026-11-14)
- 2편 (8곡, 39분): 영상·썸네일·업로드 문구 완성, 업로드 전

## 정한 것 (사용자 결정 2026-11-14)
- 곡: 저작권이 끝난 옛 찬송가만 (작곡가 사망 70년 지남 + 미국 기준 1930년 이전 출판). 가사 없이 연주만
- 악보: Open Hymnal (openhymnal.org, 공개 저작물) 4성부 ABC → `찬송가/악보/`, 읽기 `전통악기/찬송가_악보.py`
  (hymnary.org 는 자동 접속 차단 — 우회하지 않음). 기억으로 멜로디를 적지 않음
- 악기: **B판 = 가야금 + 해금 + 장구** (`전통악기/가야금_찬송가_수면.py --편 N`). 한 곡을 가야금 → 해금 → 함께 세 번, 2부는 같은 곡을 더 느리고 작게, 끝 30초 서서히 작아짐
- 편마다 따로 만듦: 새 곡은 기존 편에 넣지 않고 새 편(ALBUMS 에 "3" …), 결과 폴더 `찬송가/가야금_수면N/`
- 영상: `찬송가_연주영상.py` — 곡마다 그림 한 장, 천천히 확대·축소, 곡 사이 어두워졌다 밝아짐, 24fps 가로
- 그림: **고흐 화풍의 현대 밤 도시**, 사람·글자 없음 (가게 창 속 사람·간판 글자를 검수에서 잘 놓침 → 크게 확대해서 확인)
- 제목: **역사 이야기 중심** (곡이 태어난 사연). 영상에는 **나레이션 없음** — 곡이 처음 나올 때 제목 아래 이야기 한 줄 글자만 (`곡이야기.txt`, '제목|이야기')
- 전해지는 이야기(타이타닉 악단·바위틈·감옥 예배)는 '~했다는·전해지는'으로, 단정하지 않음 (영상·썸네일·설명 모두)
- 장 번호: 확인한 것만 적음 (통일찬송가 405·470·364·487·204·478장). 모르면 제목만
- 썸네일 A/B/C 세 개 + 그림 후보 모음, 업로드 문구에 곡 순서(챕터)·곡 이야기·태그 칸
