# 실화 쇼츠 8편 → PC에서 MP4 만들기

`실화_대본`의 롱폼 8편에서 가장 놀라운 장면만 뽑아 만든 **세로 쇼츠 대본**(편당 약 40~50초)입니다.
롱폼과 **같은 목소리·글꼴**을 쓰고, 화면만 세로·자막형으로 바꿨습니다.

## 영상 만들기 (한 편)
프로그램 폴더(`short_`)에서:

```
py -3.11 -X utf8 render_project.py "실화_쇼츠\1_별불가사리.json" --사진 8 --kit --suffix 쇼츠
```

- `--사진 8` : 근거 사진을 웹에서 찾아 나레이션 **8초마다 한 장** 넣음 (쇼츠라 롱폼보다 촘촘하게)
- `--kit` : 쇼츠용 제목·설명·해시태그·고정 댓글
- `--suffix 쇼츠` : 결과 파일 이름 끝에 `_쇼츠` (롱폼 파일과 헷갈리지 않게)
- `--소재프로필`은 **쓰지 마세요** (롱폼 다큐 스타일을 입혀 가로 화면이 됨)

결과: `output\장문\<제목>_쇼츠.mp4`

## 8편 한 번에 (PowerShell)
```
Get-ChildItem "실화_쇼츠\*.json" | ForEach-Object { py -3.11 -X utf8 render_project.py $_.FullName --사진 8 --kit --suffix 쇼츠 }
```

## 올리는 법 (롱폼으로 연결)
- 쇼츠 마지막 줄이 "전체 이야기는 채널의 긴 영상에서"라서, **고정 댓글에 해당 롱폼 링크**를 꼭 달아 주세요.
- 유튜브 쇼츠 편집 화면의 **관련 동영상**에 같은 주제 롱폼을 연결하면 쇼츠에서 롱폼으로 바로 넘어갑니다.
